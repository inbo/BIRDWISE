# BIRDWISE
Data verwerking van het BIRDWISE project

**Mappenstructuur**

- Input/ — Invoergegevens voor de analyses, zoals vogeltellingen, schademetingen, ruimtelijke gegevens en informatie over beheermaatregelen.

- Scripts/ — Scripts voor het inlezen, opschonen, combineren en analyseren van de gegevens.

- Output/ — Gegenereerde resultaten, zoals verwerkte datasets, tabellen, figuren en kaarten.
