# BIRDWISE
Data verwerking van het BIRDWISE project

**Mappenstructuur**

- Input/ — Invoergegevens voor de analyses, zoals schademetingen, GPS-tracking data, ruimtelijke gegevens, ...

- Scripts/ — R-scripts voor het inlezen, opschonen, combineren en analyseren van de gegevens.

- Output/ — Gegenereerde resultaten, zoals verwerkte datasets, tabellen, figuren en kaarten.
